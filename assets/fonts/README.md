# Fonts

Fonts used by the LCD stats overlay, all from
[Google Fonts](https://github.com/google/fonts). Each folder contains its
licence: SIL Open Font License 1.1 (`OFL.txt`) or Apache License 2.0
(`LICENSE.txt`).

| Folder | Font | Used by |
|---|---|---|
| `sniglet/` | Sniglet ExtraBold | Kawaii style |
| `vt323/` | VT323 | Retro terminal style |
| `metalmania/` | Metal Mania | Heavy metal style |
| `luckiestguy/` | Luckiest Guy (Apache 2.0) | Saiyan style |

The Terminal style uses Hack, which ships with egui (`epaint_default_fonts`).
