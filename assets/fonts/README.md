# Fonts

Fonts used by the LCD stats overlay. All are licensed under the SIL Open Font
License 1.1 (see `OFL.txt` in each folder) and come from
[Google Fonts](https://github.com/google/fonts).

| Folder | Font | Used by |
|---|---|---|
| `sniglet/` | Sniglet ExtraBold | Kawaii style |
| `vt323/` | VT323 | Retro terminal style |
| `metalmania/` | Metal Mania | Heavy metal style |

The Terminal style uses Hack, which ships with egui (`epaint_default_fonts`).
